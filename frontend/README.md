# ShowTimeX frontend

React 18 + Vite client for the ShowTimeX API. Setup, environment variables, architecture and the demo walkthrough are in the [root README](../README.md).

```bash
npm install
cp .env.example .env   # VITE_API_BASE_URL, VITE_RAZORPAY_KEY
npm run dev            # http://localhost:5173
npm run lint && npm run build
```
